Behind the build

My process.

These are the simple steps I follow when working on a new web assignment.

  1. Read the requirements carefully.
  2. Sketch the content and page layout.
  3. Build with semantic HTML.
  4. Style the page for desktop and mobile.
  5. Test every action and link.
  6. Publish and improve.

What comes next?

Keep practicing accessible design, JavaScript and full web applications.
